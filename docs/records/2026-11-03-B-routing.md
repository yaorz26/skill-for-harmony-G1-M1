## 2. 路由与编排覆盖内容

| 类别 | 用例与断言 |
| --- | --- |
| 路由表 | `回显`/`echo` → `g1-echo`，`长度`/`字数`/`length` → `g1-text-length`；首尾及前缀后多余空白去除，参数内部空格保留 |
| 缺参 | `回显`、`回显   ` → 命中 `g1-echo` 后返回 `ERR_INVALID_PARAMS`，不触发 `skill_started` |
| 未命中与分隔符 | 未知前缀（`查天气`）、大小写不符（`Echo x`/`ECHO x`/`Length x`）、无空格（`回显你好`）、制表符/全角空格分隔 → `ERR_NO_SKILL` |
| 相邻意图与最长前缀 | `回显 长度 abc`、`长度 回显 x` 不二次路由；`回显长度 abc`、`echoes x` 不误命中；多前缀重叠（如 `查` 与 `查 天气`）与注册顺序无关，稳定命中更长前缀 |
| 长度边界 | 参数 1024 通过、1025 返回 `ERR_INVALID_PARAMS`（保留 `skillId`）；整条输入 1100 进路由、1101 初检拦截 `ERR_INVALID_PARAMS`（`skillId` 为空）；空白 `requestId` 初检拦截 |
| 确定性与目录防篡改 | 同一输入连续 100 次结果一致；`SkillRegistry.list()` 与 `get()` 返回防御性副本；构造时拒绝非法 `id`、空名称、首尾/制表符/全角空白前缀及重复 `id`/前缀 |
| 可替换边界 | 自定义 `SkillInvoker` 透传 `executionPath`；自定义 `IntentRouting` 返回未注册 `skillId` 时按 `ERR_NO_SKILL` 拦截；返回全空白参数时统一 `trim` 后按 `ERR_INVALID_PARAMS` 拦截；路由抛错返回 `ERR_INTERNAL` |
| `requestId` 关联 | 并发三路请求（回显、长度、未命中）结果不串包；各 `requestId` 的 `[G1M1]` 阶段顺序固定，日志不含用户全文 |
