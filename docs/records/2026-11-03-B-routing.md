## 2. 独立路由与目录覆盖内容

| 类别 | 用例与断言 |
| --- | --- |
| 路由表（同步/异步一致） | `回显`/`echo` → `g1-echo`，`长度`/`字数`/`length` → `g1-text-length`；首尾及前缀后多余空白去除，参数内部空格保留；`route`、`match`、`routeAsync` 结果完全一致 |
| 缺参 | `回显`、`回显   ` → 命中 `g1-echo` 且参数为空，`evaluate` 与应用内链路均稳定判定 `ERR_INVALID_PARAMS` |
| 未命中与分隔符 | 未知前缀（`查天气`）、大小写不符（`Echo x`/`ECHO x`/`Length x`）、无空格（`回显你好`）、制表符/全角空格分隔 → `ERR_NO_SKILL` |
| 相邻意图与最长前缀 | `回显 长度 abc`、`长度 回显 x` 不二次路由；`回显长度 abc`、`echoes x` 不误命中；重叠前缀（如 `查` 与 `查 天气`）与注册顺序无关，稳定命中更长前缀 |
| 独立请求预检 `evaluate` | 不依赖 `AgentService` 和 `SkillExecutor` 直接测试：空白 `requestId`、空白输入、1101 码元超长输入（初检 `ERR_INVALID_PARAMS`）、1100 码元未命中（`ERR_NO_SKILL`）、1024/1025 参数边界 |
| 确定性与目录防篡改 | 同一输入连续 100 次结果一致；`SkillRegistry.list()` 与 `get()` 返回防御性深拷贝；构造时拒绝非法 `id`、空名称、首尾/制表符/全角空白前缀及重复 `id`/前缀 |
| 现有 `AgentService` 兼容性 | 零改动兼容 `e9bf728` 的 `AgentService`（含自定义 `SkillInvoker.executionPath` 透传与并发三路 `requestId` 阶段关联），日志不含用户全文 |
